# Control de Gastos para Estudiantes 🎓💸

Este proyecto es una solución en Python para la problemática de la gestión financiera personal de los estudiantes. Permite registrar ingresos, gastos por categoría, calcular el saldo disponible y generar alertas de presupuesto.

## 🚀 ¿Cómo ejecutar el programa?
1. Abre una terminal.
2. Ejecuta el comando: `python gastos.py`
